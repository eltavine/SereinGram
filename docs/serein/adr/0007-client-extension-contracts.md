# ADR-0007：扩展交互的接入边界

- 状态：Accepted
- 日期：2026-11-07

## 决定

消息范围选择由原消息列表拥有状态。菜单动作启用范围模式；后续选择增加时，
按列表中的现有顺序补全首尾之间的可选消息，清空或缩小选择时退出该模式。
扩选受相同选择上限约束，不主动加载尚未显示的历史消息。

展开播放器复用上游播放器控件、播放实例与下载后的封面，避免维护第二套播放状态。
双击入口、头像状态点和选择更新使用薄挂钩；配置、菜单与绘制逻辑留在各自领域。
封面交给系统图片程序打开，导出保存为 PNG。播放快捷键避开文本编辑器和按钮。

## 上游侵入预算

新增产品能力需要新的生命周期调用点，属于 ADR-0001 的挂钩扩展。
本次允许将预算调整到新增挂钩的实际数量；直接引用内部实现头文件仍为零。
范围选择、音乐播放器和头像状态的新增调用各保持一个入口，后续只允许随实现收敛降低预算。
子模块定制的字体配置入口不依赖 Telegram 或 SereinGram 的业务类型。
