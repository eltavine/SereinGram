# ADR-0007：扩展交互的接入边界

- 状态：Accepted
- 日期：2026-11-07

## 决定

消息范围选择由原消息列表拥有状态。菜单动作启用范围模式；后续选择增加时，
按列表中的现有顺序补全首尾之间的可选消息，清空或缩小选择时退出该模式。
扩选受相同选择上限约束，不主动加载尚未显示的历史消息。

展开播放器复用上游播放器控件、播放实例与下载后的封面，避免维护第二套播放状态。
双击入口、头像状态点和选择更新使用薄挂钩；配置、菜单与绘制逻辑留在各自领域。
封面交给系统图片程序打开，导出保存为 PNG。播放快捷键避开文本编辑器和按钮。

下载列表按当前账号与媒体类型投影上游记录。顺序队列由会话拥有，取消、超时
和会话销毁会释放正在进行的传输。照片由队列跟踪，只有成功保存后才加入下载历史。
消息缓存清理与手动保存的文件互相独立。

隐藏聊天是本地列表和通知规则。隐藏账号复用本地密码校验与重试限制，并在账号
切换、窗口恢复、未读计数和通知入口应用同一可见性规则。关闭新建隐藏账号的
入口不会自动恢复已经隐藏的账号。

账号连接开关由该账号的 MTProto 实例持有。暂停时关闭该账号的通话和小程序，
并中止该账号发起的 HTTP 下载与外部翻译、摘要、转写请求。更新检查等应用级
联网功能仍独立运行。

第 3 版设置文件通过适配器导出明确列出的原生设置。差异预览同时验证原生与
SereinGram 设置，现有的第 1、2 版文件继续可导入。自动备份仅在本地导出成功
后上传同一份内容，不收集授权密钥或其他账号的配置。

## 上游侵入预算

新增产品能力需要新的生命周期调用点，属于 ADR-0001 的挂钩扩展。
本次允许将预算调整到新增挂钩的实际数量；直接引用内部实现头文件仍为零。
下载、账号状态和聊天列表改动通过现有会话、窗口和数据模型的生命周期接入；
业务逻辑留在对应模块。子模块的字体和输入粘贴接口不依赖应用业务类型。
